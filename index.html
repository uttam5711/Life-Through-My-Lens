How to get a Free GitHub Token

  1. Log into your GitHub account in your browser.
  2. Click your profile picture in the top right → Settings.
  3. Scroll down on the left sidebar and click Developer Settings (at the bottom).
  4. Click Personal access tokens → Tokens (classic).
  5. Click Generate new token → Generate new token (classic).
  6. Give it a Note (e.g. Photo Gallery Uploader), set Expiration to 90 days or No expiration, and check the repo checkbox (Full control of private repositories / code).
  7. Click Generate token at the bottom. Copy the token (starts with ghp_...) and paste it into the Upload Studio!
Privacy note: The token is saved only in your own computer/phone's browser localStorage. No external server ever sees or stores your token.
